# R01 receipt. Repair checks and test the built artifact

- Starting commit: baseline `d6d6b174e82e3b59f7be2bb350443fcc9bb254de`
- Baseline lint failure reproduced first: `scripts/verify-production.mjs 28:1 'console' is not defined no-undef`.

## Changes

- `eslint.config.js`: scoped Node globals block for `scripts/**/*.mjs`. `no-undef` stays on everywhere; application rules untouched.
- `package.json`: added `test:e2e:build` as the explicit build-plus-test command. `test:e2e` no longer builds.
- `scripts/serve-production.mjs` (new): static server for an existing `dist/` with correct MIME types (including `.bcmap`, `.pfb`, `.mjs`), path-traversal guard, fails fast when `dist/` is absent.
- `playwright.config.ts`: webServer now runs `node scripts/serve-production.mjs` against an existing build. No implicit second build.
- `vite.config.ts`: `build.manifest: true` so the artifact carries a dependency graph.
- `scripts/verify-production.mjs`: resolves initial chunks by walking the Vite build manifest from the `index.html` entry scripts, then static imports transitively. Validates every script and stylesheet reference against the manifest. Removes `dist/.vite` after verification. Writes a sha256 file-hash manifest plus commit SHA to `test-results/readiness/R01/artifact-manifest.json` (outside `dist/`). Budget unchanged: initial JavaScript below 300 KiB gzip.
- `.github/workflows/ci.yml`: Node pinned to 24, runs `node scripts/check-deploy-gate.mjs`, `npm test -- --maxWorkers=2`, builds once, verifies, then e2e serves the built directory.
- `.github/workflows/deploy.yml`: deployment now triggers on `workflow_run` of `ci` and the build job is eligible only when CI concluded `success` on the same commit; publish (`deploy`) depends on that gated build. GitHub Pages publishing remains until R11 replaces it.
- `scripts/check-deploy-gate.mjs` (new): workflow test fixture. Parses `deploy.yml`, requires the `workflow_run` trigger on `ci` completion and the `conclusion == 'success'` gate, and evaluates publish eligibility for success/failure/cancelled conclusions.
- `tests/e2e/helpers/fixtures.ts` (new): shared generated PDF fixtures (`createSamplePdf`, `createBatchPdf`, `createPerformancePdf`, `pdfFixture`) and `SAMPLE_UPLOAD_PNG`. `sign-flow`, `batch-flow`, and `batch-performance` specs now import them instead of redefining generators.
- `README.md`: documents the Node 24 and npm 11 requirement.
