# R10 receipt. Keyboard access and local data

## What a user can do

A user can open the pages and library sidebars from the keyboard on a 360 CSS-pixel window. Desktop at 1,280 CSS pixels keeps both sidebars visible. Tab moves through a dialog in both directions and skips a disabled Save. Escape closes the dialog that contains the focused control, and focus returns to the button that opened it.

Clear document history removes saved Work Sessions and keeps the signature library. Clear all local data removes sessions and signatures. Cancel changes nothing. The current editing tab already holds the session lock, so it clears directly. A read-only tab, a running batch, and a browser without Web Locks are refused before anything is erased.
